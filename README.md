# Blue Bell Cafeteria

Static website for Blue Bell Cafeteria, Al Quoz, Dubai.

## Deploy to Vercel

Import this repository into the intended Vercel team. Use project name `bluebellcafe`, framework preset **Other**, and leave Root Directory at the repository root. `vercel.json` sets the output directory to `dist`; no build or installation is needed.

The site includes the menu, Arabic language switch, WhatsApp ordering links, and the menu assistant.
